# 제출 파일 점검

점검일: 2026-11-10. 점수 보장이 아니라 파일과 증거의 확인 기록이다.

- README에 필수·선택 5종의 수행 항목, 실행 환경, 빌드·실행 절차, 검증 링크, 트러블슈팅을 연결했다.
- CLI·볼륨·바인드 마운트의 부족했던 보고를 후속 검증의 실제 출력으로 보완했다. 과거 출력으로 소급해 생성하지 않았다.
- 포트 접속·VS Code WSL 폴더·GitHub 계정 화면 3개를 직접 확인했다. 비밀번호·토큰·개인키·인증 코드는 화면에서 식별되지 않았다.
- Markdown의 로컬 파일 링크 점검에서 누락 0건이었다.
- 전송 대상으로 고른 문서에서 개인키 헤더·GitHub 토큰 형태의 패턴 검사 결과 검출 0건이었다. 이 자동 검사는 모든 종류의 비밀값 부재를 보장하지 않으며 실제 이미지와 기록 내용도 함께 검토했다.
- GitHub 저장소는 public이고, 통합 전 원격 main의 커밋은 bd7e9e1ff02f520f81d791719aacd063be211594였다. 기존 소스 4개와 notes.txt 및 Git 이력을 보존하며 문서를 추가한다.
- 개인 공부메모, 원본 스크린샷 중복 파일, practice1, cli-review 실습 폴더, SSH 키 파일은 도우미의 문서 업로드 대상에 넣지 않는다. 증거용으로 정리한 화면 3개만 포함한다.
- WSL의 현재 실행 환경을 도우미가 다시 빌드한 것은 아니다. 실제 빌드·운영 검증은 학습자가 제공한 결과를 근거로 한다.

수행은 완료해도 과제 목표를 혼자 설명하는 학습 점검은 이어갈 수 있다. 설명이 부족한 항목은 [설명 학습 기록](explanations.md)에 보충하며 답변을 임의로 대신 만들지 않는다. 원격 통합 게시 성공은 실제 Git 결과와 게시 파일 조회로 따로 검증한다.
