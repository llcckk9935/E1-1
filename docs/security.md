# 증거 보호 학습 기록

## 챕터 1 — 민감정보와 마스킹

가상 예시를 사용했으며 실제 자격증명을 사용하지 않았다.

학습자 답변:

> 가상토큰_연습용 이 부분을 [REDACTED]로 치환해서 마스킹해야 한다. 왜냐하면 토큰값은 프로그램이 인증에 사용하는 비밀값이기 때문에 노출되면 안되서

도우미 확인: 비밀값의 식별, 마스킹 방법과 이유를 설명했다.

```text
ACCESS_TOKEN=[REDACTED]
```

로그는 수행한 작업과 발생한 결과의 기록이다. 제출용 CLI 기록에는 입력 명령과 실제 출력을 함께 남긴다. 오류도 기록 대상이다.

## 도우미가 수행할 기록 검토

- 저장 전: 텍스트와 이미지를 읽고 토큰·비밀번호·개인키·인증 코드·인증정보 포함 URL과 불필요한 개인정보를 확인한다.
- 커밋 전: 저장 대상과 스테이징한 내용을 확인한다.
- 푸시 전: 전송할 커밋 및 증거 이미지를 확인한다.
- 이미 공개한 자격증명은 마스킹만으로 해결됐다고 판단하지 않는다. 폐기·철회, 재발급, 설정 교체와 가능한 범위의 문서·Git 이력 정리를 수행하고 검증한다.

위 보호 절차 전체와 SSH 키의 구분은 앞으로 해당 단계에서 학습하고 확인한다. 현재 확인한 이해도는 가상 토큰의 식별과 마스킹까지다. 실제 자격증명 노출은 확인되지 않았다.
